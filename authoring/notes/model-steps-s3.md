# S3 已验证任务提炼的候选经验

来源：[S3 原始验收](../../docs/validation/20261023-S3-hermes-1fc35736cd.json)、[数值/边界测试](../../tests/analysis_models/test_model_steps.py)。此文件是后续技能迭代的离线材料；不由运行时检索后自动当可信指令，不自动修改发布技能。

| 已验证事实 | 可泛化的候选约束 | 后续独立留出验收 |
| --- | --- | --- |
| 实际五步骤逐级传真实 reference，得到四条成功回执 | 技能必须检查每步 status，阶段引用只来自上一步工具结果 | 换输入、不同模型包、多个批次，不能只在本合成样本成立 |
| ENU 轴向误差使用 m；UTC 起点加相对 s 保留 | 报告明确单位、起点与坐标约定，不把 ENU 误差写成经纬度 ADE | 经纬度轨迹、含缺失值/无真值、不同输出目标 |
| 模型/组件摘要、scope/run 与中间制品绑定 | 上游变化时重新准入，禁止只改展示引用或继承未授权父技能权限 | S4 批准 job 修订、技能版本撤销、跨子 run 显式委托 |
| 成功重复复用，计算后丢失提交拒绝重跑 | 技能遇 unknown 转核实，不换参数/调用 ID 规避 | S4 实际后端断联/租约故障；来源日志只是证据，不替代核实结果 |
| 三次 API 临时恢复仍消耗同一额度 | 外部重试也计入实际调用预算，不能让子 Agent 获得新的完整额度 | S4 跨 session/worker 重启累计；S6 多次稳定性 |

当前 `scat-model-analysis:0.1.0` 已作为开发者维护的文档技能通过本阶段测试；本材料不宣称 Agent 自主创作、自动发布或通用模型选择准确率已实现。候选修改在 S6 使用独立留出题比较，正式作者流程仍属 S7。
