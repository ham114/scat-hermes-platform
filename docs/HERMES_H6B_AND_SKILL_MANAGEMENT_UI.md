# 动态结果工作台与技能管理

## 动态展示

对话中的实际结果预览增加“展示调整”输入区。使用原内容编号，不依赖排序后下标：单列/双列；置顶 2；隐藏 3/显示 3；升序 2 字段/降序 2 字段；只看 2 字段1 字段2；折线图/柱状图/默认图表；恢复默认。多个指令以中文或英文分号/逗号分隔，任何一条非法则整次不应用。只允许受控展示描述，不执行脚本、不改变指标单位或原始结果、不触发模型或计算。未支持的自然语言明确提示；重新分析应通过原对话提问流程。本轮不宣称任意自然语言LLM布局编译。

保存展示仅持久化version/columns/order/hidden/chart/sort/fields，不持久化结果正文。键为hermes-display-v1:artifactId:payloadSha256；固定内容变化不会误套旧配置。再次打开同一结果时按当前浏览器配置恢复，跨浏览器同步不在本轮范围。存储不可用、非法配置明确提示并回退；不自动保存。排序和选列仅作用于当前已加载表格页，不冒称全量表全局排序。手机双列自动折为单列。

地理轨迹的“打开轨迹交互”复用原二维播放、三维Cesium、播放控制、高度/速度曲线；快照切换、播放/暂停、倍率、游标、三维跟随/视角/高度倍率/底图/全屏沿用原组件。新增每个工作台自己的Pinia时间游标，避免多个结果互相干扰；原专用可视化页通过兼容回退仍使用原全局游标。米制相对坐标保持原二维绘图，不将其伪装为经纬度。Cesium按需加载，原始明细/单位/路径分段保留。

## 技能管理

新路由/skills，首页不自动读取目录或数据集。作者先输入凭据并连接，方读取版本/精确依赖/输入输出/操作与SKILL.md及附属资源。选技能生成可编辑草稿JSON，更新已有技能须升版；多技能组合可在changes中同时修订依赖。组合参数限定契约输入，生成明确版本与包摘要的提示，带入对话输入框，仍须用户手动发送，不自动计算或批准。

草稿创建、保存修订使用expected_sha256，支持修订历史、历史版本读取、完整逐文件/元数据差异和静态校验。试跑须勾选消耗额度确认，异步启动后可刷新报告，也可输入已知试跑编号恢复报告。仅已通过且对应当前已保存修订的试跑开放发布预览。修改编辑器、保存或切换草稿使旧预览失效。发布历史提供回滚预览；最终切换须核对预览/有效期、另勾选确认并输入独立发布凭据。确认派发前清空预览，结果不明不得自动重发；既有后端仍负责ABA/代码/策略/试跑/修订/到期校验与事务发布。在途运行保持原技能包。

## 作者接口与路由

前端同源/author-api/v1/skills/*代理到独立作者服务/v1/skills/*。开发代理使用SCAT_AUTHOR_PROXY_TARGET（默认回环18124）；不向作者服务转发业务AUTH_SECRET。正式网关尚未配置这一入口，不能仅同步构建包就声称界面已在生产开放。正式入口应仅向受信维护人员开放并使用TLS与访问控制；当前作者服务是固定actor，不提供多用户作者隔离。

作者凭据由操作者输入，仅页面内存；离开清空，不使用localStorage/sessionStorage/VITE变量/URL或日志。独立发布凭据每次操作结束清空，不交给模型。只读预览隐藏写权限，写入按钮禁用；本轮未扩大旧只读代理权限。没有自动启动真实试跑或正式发布/回滚。

新增GET /v1/skills/catalog?bundle=<已注册包摘要>，沿用X-SCAT-Author-Key认证；不指定时为当前包。响应{bundle_sha256,items:[{name,version,allowed_operations,requires_skills,contract,files}]}，files为相对路径到UTF-8正文。只返回可直接用作changes条目的白名单字段。返回受既有包大小限制；无鉴权401，非法或未注册包沿用作者服务拒绝规则。其余接口与错误/发布契约复用[作者接口](HERMES_S7A_AUTHORING.md)。浏览器单次请求30秒、有界响应、不重试写入；作者与发布凭据独立。
