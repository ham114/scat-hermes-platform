## 剩余问题与优先级

1. **P1：补加载恢复代码未完整进入现网。** 活动release仍`20261107-track-display-3ee814b9c60b`，运行镜像内SkillOperationGuard没有load_required，skills_list没有allowed_operations，活动镜像技能包仍s5-gpu.1.0；查询/轨迹技能实际0.2.0。系统提示虽已要求按recovery.skills补加载，但拒绝响应根本不提供recovery。现网子进程的真实native分发实测：错技能→拒绝；手动显式补加载正确技能→成功；换run→重新拒绝；两种拒绝均无恢复提示。本次没有靠解除守卫求通过。源码候选的相关95项通过，不等于运行镜像具备这些修复。
