## 范围与验收门槛

S6 收口 S1–S5 已迁移的有界 CPU 后端，不扩大生产 GPU、全库物化、通用前端图表或正式技能作者 API。十一业务域为查询、轨迹、质量、知识、UAV、预测、对比、实验、物化、评估、报告。原 H2 至少 20 题及 S2 逐域失败矩阵保留；新增独立于草稿示例的 `evaluations/hermes_s6_holdout_v1.json`。

真实固定 Hermes/DeepSeek 代表题逐题至少三次，最多十次；每域完成及选择/参数准确率均至少 90%，分子/分母逐域展示。组合题共用一个实际运行，分别贡献相关域的统计，绝不把域分母相加冒充独立运行数。失败、用量和耗时全部保留，不以最后一次成功覆盖失败。单次预算延续部署配置，整题集另限 400 次 LLM、25000000 保守 token 单位、10800 秒；新题前预留一次最大预算。无经过核验的价格表时费用估计为 null，报告供应商 input/output/cache 与保守准入额度，不声明账单硬封顶或 SLA。

真实验收验证 Skills 正文加载、实际参数、只读引用/数值、确认前零效果、重复确认单 job、独立后台各单元 calls=1、标准结果实际回读、跨线程 404；确定性回归单独覆盖空数据、缺参/非法参数、故障、权限、预算恢复、旧数值与历史结果兼容。真实数据验证继续引用服务器内 S5 证据；本轮模型题仅使用合成源。

## 容量、归档、缓存和会话

`skill_loads` 与 `skill_operations` 共用热容量。可信 run 绑定/完成状态持久化；无状态旧记录、active、未完成 admitted/unknown 调用和显式 held 记录受保护。finished run 在高水位或热保留期触发归档，先写入冷记录并核对内容与 SHA，再清理热记录；这些动作在同一 SQLite 事务提交，不存在跨文件提交窗口。冷记录包含归属、run、原始 ID、正文/操作关联、发布/策略摘要和终结时间，读取同时校验权限范围及内容摘要。总保留期从 run 终结时间计算；held 记录不过期。共享预算账本与后台任务后端证据保持原持久存储，不随聊天闲置释放。

冷热表位于同一个 0600 SQLite 文件，冷热迁移使热容量释放，SQLite 空闲页可复用；不会声称归档立即缩小文件。SQLite 满页/存储错误时拒绝新操作，不伪造回执。失败事务、真实进程 SIGKILL、并发维护、损坏、保留保护和历史数据保守迁移均有专项测试。尚未核实结束的历史运行需要维护者核实后再处理，不自动推断安全终态。

维护入口为现有 Conda 执行 `scripts/manage_skill_traces.py --state <项目相对数据库> --action maintain|read|hold|release|preview|apply`。scope/run 只能来自可信维护者绑定；该 CLI 不注册为模型工具。缩短保留期限先停止该 profile 的新准入并核实在途状态，再 preview，使用对应 preview_sha256 apply，随后部署同一候选配置；直接重启加载更短期限会拒绝。活动保护继续生效。H7 再接持久卷、定时维护和告警。

主 Agent 准备后台任务时会登记对原回执数据库的引用。维护时核对所有引用任务的持久状态和快照摘要；任一 pending/queued/running/unknown/cancel_requested 仍保护主运行，多个任务均核实终态才解除。状态库不可读、丢失或摘要不符时继续保留，不以聊天结束代替子任务结束。专用存储之外，既有 MCP 桥接仍在项目 `.tmp/mcp` 建立临时缓存骨架；收尾审计仅移除空目录，不删除其他任务数据。

目录缓存仅存不可变技能目录，不存业务数据/正文加载信任。键包含可见 scope、发布摘要及目录身份，LRU/TTL 使用用户配置。每次命中仍检查实际技能树与原生搜索根；返回深拷贝。发布或范围变化不复用旧键；目录缓存不会生成当前 run 的加载回执。闲置会话只释放已经结束且超时的绑定；活动任务保护、历史结果读取和后台累计预算不受影响。

## 新入口与历史兼容

平台 `HERMES_SKILL_JOBS_ENABLED`、`HERMES_WORKFLOWS_ENABLED` 默认 true；native 启动不指定能力时默认 MCP+Skills+任务+工作流。历史 H5 使用显式 `--legacy-h5`；后台进程继续使用批准的最小操作集。旧结果/旧模型记录/旧物化只读 REST 保留，未切换现网 Nginx 或原项目。回滚只影响新准入；先停止新准入并核实 in-flight/unknown，再用独立旧 profile 和显式关闭两个平台开关恢复历史入口，不能让旧 worker 领取 Skills 快照。原生回执 schema 与标准 AnalysisResult 1.4 不变。

## 候选与发布基线

S5 技能包继续冻结，S6 不自动修改、安装或发布草稿。发布清单固定包及文件摘要、契约/操作清单、Conda 引用、测试证据与回滚 profile；批准在途任务仍使用其快照，内容变化失效而不偷偷换包。现有调查草稿用独立留出题做离线对照；通过仅代表对应评测，候选仍不进入已发布目录。正式作者/发布/回滚服务留 S7。
