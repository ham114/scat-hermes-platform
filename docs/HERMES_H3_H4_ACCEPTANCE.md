# H3/H4 实现与验收范围

日期：2026-10-22。当前范围为固定单用户、外部 DeepSeek 与五个只读 MCP 工具；本轮补齐已有 POC 的应用边界与结果事件，动态展示仍在 H6。

## 实现

| 阶段项 | 实现和证据入口 |
| --- | --- |
| 轨迹大结果 | 默认 20 点、最多 100 点；超字节预算返回明确的已读取页摘要，超小预算仍明确拒绝 |
| 参数、错误、身份边界 | 非法批次、分页、注入参数、超时、缺失上下文及错误用户在业务调用前拒绝；MCP 错误标志与业务状态一致 |
| 三种入口一致性 | 同一个合成 Repository 经真实 Service、REST、旧 Tool 和实际 MCP 协议验证检索/轨迹；覆盖空结果、分页/抽样、坐标/高度和 UTC 等价表示 |
| 业务结果引用 | 固定版原生完成回调产生真实收据，SQLite 按 scope/run/call 隔离；列表/读取、重放、过期、容量、并发和完整性有测试 |
| SSE 与恢复 | business.result 仅转发经当前归属校验的收据引用；get run 返回可恢复的引用列表，原文本/工具/终态契约保留 |
| 停止语义 | stopping 不算已取消；真实 cancelled/interrupted 后才结束。接口和页面说明仅停止对话，不取消独立业务任务 |

只读结果收据不是模型作业 artifact；字段和启动方式见 [API 指南](HERMES_API_AND_PORTAL.md)。消息流仍按固定版 Hermes 原生协议适配，本轮没有引入 AG-UI 或更新上游版本。

## 范围与验收口径

- 当前身份仍是固定 single_user。测试覆盖固定身份拒绝、两套独立应用上下文和 scope/run 结果隔离；不能据此声称已实现多用户登录、共享 Hermes profile/MCP 文件记忆的生产隔离。
- 合成三入口对照覆盖有 REST 对应的检索和轨迹，包括空结果和抽样。五工具真实业务与固定 20 题另有前轮证据；不宣称本轮将 RAG 新增成了 REST 查询端点。
- 真实 DeepSeek 集成验证查询总数、3 点轨迹、引用 SSE 与读取、摘要完整性、跨会话拒绝、重放、原生取消和 Hermes 离线降级。没有提交 GPU 任务；已提交业务作业独立于对话的语义由受控夹具验证，H5 继续验收真正的 prepare/confirm/submit/status/artifact 闭环。
- 浏览器回归使用模拟接口，真实服务器链路由独立集成验证；截图含“验证样例”和文本转义用例，不当作真实模型输出。
- 既有 Nginx SSE 传输验证继续适用。本轮未切换正式入口或新增常驻服务；完整会话历史、动态结果图表、模型任务、Compose 和生产多用户按后续原计划推进。

前轮记录见 [H3/H4 POC](validation/20261022-H3-H4-business-api-portal.md)，本轮最终结果与清理状态在 validation 的 20261022-H3-H4-completion / cleanup 记录中维护。保留失败报告，不把协议断言修复回填到原报告。
