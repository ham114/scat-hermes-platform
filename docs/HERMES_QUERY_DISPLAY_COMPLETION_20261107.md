## 实现范围

- 将适用技能恢复信息与技能列表allowed_operations同步到实际运行代码；技能版本来自当前已发布目录，保留现有技能包、归属守卫与每run加载约束，不整体替换为含其他未发布模块的候选。
- 从本轮受控回执生成确定性已读去重点数/源总数，主对话最终回复包含系统核验区块，移除冲突的全量读取声明。显示扩展回执标为display_only，不混入模型实际分析点数；后台任务结构化输出不应用此文字转换。
- 明确绘图请求仅为当前最后一条已完成回复自动展开主图；历史其他回复及非绘图请求保持按需读取。兼容旧接口/夹具，没有能力标记时保留手动方式。来源明细继续折叠。
- 新受控trajectory视图从已验证的seed回执派生batch/flight/时间窗口，程序分页读取当前范围；最多2000点，超限按全程抽样并保留首末点。首次创建持久化显示回执，刷新复用缓存，不触发模型或再次取数。用户、run、摘要、过期校验在缓存命中前仍执行。页面区分模型分析范围和地图展示范围。
- 对有效时间分页对齐真实公共起始时间，无时间时仍为静态几何；不补造时间/坐标。部分失败保留部分范围并提示，不声称完整；已有原始回执和内容摘要不变。
- 大轨迹遵守业务`every_nth<=20`限制；超过均匀步长上限时采用20段有界抽样并补末点，明确标为分段抽样。每次视图最多2000点、22次只读业务调用、24秒聚合期限，失败不自动冒称全量。展示页不能作为再次扩展的seed。
- 前端先核验所有分页引用，再同时发布轨迹与覆盖元数据；单页读取失败保留原图并提示。多航班结果保留各自入口，扩展一架不会隐藏另一架或将它的范围套到另一架。
- 历史已完成回复在API返回时也校正覆盖范围，原始journal不重写；旧224/524误称全量的记录已在桌面、手机回读核对。
