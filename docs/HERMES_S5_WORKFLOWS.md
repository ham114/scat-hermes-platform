## 本轮目标与实施顺序

用户确认按业务工具组划分继续 S5，并要求无阻塞时完成本阶段，同时实际检查已有前端展示。历史 S4 的单 CPU 模型链路与验收报告保留。本轮依次交付：严格的业务方案/样本清单与工具组登记 → 批量对比、派生物化、有限实验与报告的独立操作 → 批准 job/委托/预算/恢复衔接 → 技能正文与操作映射 → 契约/数值/故障/真实合成模型验收 → 前端现有入口验证、文档与同步清理。

业务流程由 Hermes 根据技能组织。Python 提供确定的数值操作及授权/状态核实；现有实验 runner、物化 jobs 和旧 Agent 图不作为新工作流总调度。复用其纯计算、仓储和结果协议，复杂数值包保持完整输入输出契约。

## 工具组

| 工具组 | 职责 | 效果边界 |
| --- | --- | --- |
| 数据/样本 | 固定航班清单、质量与输入检查 | 准备时只读原始数据；持久输入快照归属于任务 |
| 模型/对比 | 有限注册模型和已批准试验项 | 独立执行号与租约核验，禁止新增未批准试验 |
| 评估/诊断 | 共同样本口径、阶段指标、覆盖率和最差案例 | 确定性算法，不把 LLM 文本当数值 |
| 物化 | 构建派生结果、读取版本/覆盖率 | 只写派生存储，版本化且幂等；原始集合只读 |
| 实验 | 有限参数/重复试验清单及结果汇总 | 稳定 trial 身份，共享总预算及资源队列 |
| 报告/制品 | 标准 AnalysisResult、来源、复用与导出 | 按归属和版本读取，新增计算需新批准范围 |

组名、成员工具、schema、效果类型、角色与允许技能必须在机器登记中可核对；后台按本 job 的批准操作裁剪工具。当前仅 SCAT 只读服务走 MCP，新增效果步骤先沿用可信原生桥接；外部 Filesystem/Fetch/GitHub/MongoDB/Playwright 不自动纳入本轮业务 Agent。

## 方案与执行契约

复杂方案明确 kind、样本选择、模型/参数配置、评估口径、可选派生内容、缺失处理、失败策略、报告偏好及最大试验数。准备时确定并持久化实际样本内容摘要、样本 ID 清单、试验清单和数值/组件/技能版本；人工确认绑定整体摘要。实际轨迹留服务器受控制品，不进入 LLM 工具上下文。抽样 seed 固定，恢复不重新抽样；合法参数按注册模型分别校验。样本不足返回实际数量和原因，不自动扩大范围。

一次批准的后台 job 复用 S4 租约、委托、预算、步骤回执、外部执行号及标准 run/artifact 发布。每个有意 trial/物化分片有稳定身份，成功回执复用；unknown 保持资源占用，只有核实未发生效果或有可信终态后才继续。主子与恢复会话累计计量，实际效果还有批准的试验数/样本上限。初期实际计算串行，配置并发不代表已完成 GPU 并发验收。

模型对比保留各模型有效样本和共同样本两个分母；结果包含失败、排除、缺失阶段与原协议。实验允许有限合法参数配置和重复号，禁止运行中随意扩展。物化使用数据/算法版本和业务键，不覆盖未知版本，部分成功保留证据。报告读取实际制品，改变标题/顺序可复用，改变模型/数据/效果范围需重新准备与确认。

## 验收门槛

- 严格参数/工具组/技能加载与效果授权；未批准计算/写入、跨归属读取为零。
- CPU 已注册数值路径与旧纯计算对照，样本/单位/时间轴/共同分母、覆盖率及标准结果一致。
- 批量部分失败、未知执行、重复调用、租约失效、暂停/预算修订和恢复不重复产生效果。
- 物化版本/重复构建/分片覆盖，实验固定样本/合法参数/重复身份，报告可回查与合法复用。
- 52 旧工具映射逐项闭合；未开放的维护/提升/任意执行功能明确归为控制面或未支持，不宣称迁移完成。
- 完整后端及相关前端检查、实际原生 Hermes 合成工作流、两现有 Conda 依赖检查、敏感值/端口/进程/临时目录与 SHA 保护同步。

## 已有前端核查

报告复用的当前兼容范围是同用户同会话中已完成的 S5 工作流。旧 H5/S4 结果包含的时间轴、图形协议不在此处隐式转换；原结果仍可由原 HTTP/任务制品接口读取，跨协议重排留 H6。全失败物化会保存 failed 报告及错误，不能记为 partial。

源码已有门户、总览、航班检索、单航班 2D/3D 轨迹、预测评估及分析助手路由；助手支持 SSE、多轮/刷新恢复、任务准备后的人工确认及标准结果 JSON 下载。模型任务面板目前采用 H5 状态，尚无 S4 步骤/预算和完整技能关系展示。通用七类 AnalysisResult、复杂配置套用与技能关系交互仍按 H6。

开发前服务器没有 frontend/node_modules 或 frontend/dist；本机已有 Node 依赖与构建产物。本轮用本机前端及远端隔离 API 验证当前能力，提供实测入口/边界，不为“可展示”而声称尚未实现的 H6 功能。验收演示优先合成数据，原始业务数据保持既有应用读取边界。

## 实施与证据

S5已按本文有界CPU与服务器开发范围验收；测试、真实合成委托、真实数据适配、前端展示及收尾证据已记录。下一步S6，H6/H7仍独立验收。

### 已实现的执行面

新增五份技能正文：`scat-model-comparison`、`scat-data-materialization`、`scat-evaluation`、`scat-experiment`、`scat-report`，发布包 `s5.0.0` 共 12 份技能（11 类业务及一份调查组合）。机器契约为 `services/hermes/workflow-operations.v1.json`；52 个旧工具的逐项去向在 `services/hermes/legacy-tool-mapping.v1.json`。25 个原只读定义对应既有原生 MCP（MCP 另新增一个快照列表，共26）；另有4项任务目录/状态原生控制、14项限定范围合并、7项 HTTP 人工控制、1项保留 HTTP 列表和1项未开放的生产 GPU 随机批任务。映射闭合不表示把旧52函数全部交给聊天。

主角色在原38个工具基础上新增5个流程控制工具，共43个；后台根据批准清单只注册相应独立步骤及2个技能读取工具。含模型和物化的比较实例为10个后台工具；纯报告任务为5个。加载组合技能不会继承子技能权限，准备不同 kind 也必须加载对应主技能。

五类物化均已接入有界样本：统计、飞行特征、阶段、CFPL预测指标、指标汇总。飞行特征和汇总从原 M4/M5 单元提取纯记录构造器，旧调用也使用同一构造器；旧 Agent 图、旧实验 runner 与物化 jobs 不参与新流程调度。结果保存于同任务的持久后端/步骤制品，按 scope/run/输入摘要/算法版本隔离；不更新旧全库 Mongo 物化视图。摘要物化需要明确批准并先完成指标、阶段和特征。CFPL 时域继续沿用旧 `HORIZONS_S`；M6模型时域独立配置。当前有界汇总不提供 Mongo approximate 分位数，返回空值和 unavailable，禁止补造。

固定样本最多20架、候选最多100架、配置最多8项、显式重复最多4次且总 trial 最多32项；观测窗口、噪声等按注册模型分别校验。快照保留完整原始数值但不回传轨迹给模型。`missing_phase=report_missing/require/build`、`failure_policy=keep_partial/stop` 均是用户可配置参数，受批准快照约束；缺少 require 阶段在准备时拒绝，build 需显式批准物化。预算仍由 `config/skills-policy.yaml` 部署上限约束，请求只能降低，增加预算走人工控制接口，不自动提额。

提供三份可校验配置样例：`config/workflows/comparison-synthetic.json`、`experiment-synthetic.json`、`materialization-synthetic.json`。当前可经提案 API 或助手使用；前端复杂配置套用/编辑和技能关系交互仍按 H6，不宣称已实现配置导入器。
