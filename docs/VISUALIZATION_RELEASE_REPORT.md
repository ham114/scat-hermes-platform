# 自主可视化 P6 验收与上线报告

日期：2026 年 11 月 28 日。**上线结论：No-Go，目前不具备上线条件。** P6工程物料及验收执行已完成，验收门禁未通过。生产开关仍为 `false`。本报告区分实施完成、验收结果和上线批准；不把离线测试或局部真实链路当作生产对话端到端验收。

## 本阶段交付

- 新增可选 Compose overlay：`infra/compose/compose.visualization.yaml`。默认关闭，以 `visualization` profile 启动独立 worker，复用同一任务状态库和共享产物目录。
- 宿主启动器使用 `infra/systemd/user/scat-visualization-sandbox.service`。Docker 权限留在宿主服务，worker 不挂载 Docker socket；模型代码仍在一次性禁网容器中执行。
- 模型凭据仅注入绘图 worker；平台 API、私有 actions 和主 Agent 的绘图控制接口无需 DS/Qwen key。现有 worker、作者和原 Cesium 入口不被替换。
- 关闭 worker 开关时不领取任务。启动器无法访问时保持待核实状态，不以清理失败证明容器已停止，也不让异常终止整个 worker。
- 增加固定渲染宿主、Dockerfile、依赖锁摘要；增加离线部署预检、停写备份及备份完整性检查。没有在生产环境执行切换或数据库恢复。
- 真实验收暴露输出截断、非法审核格式、多子图轴错误后，代码输出上限从4096改为8192，并同步增加预留；补充多子图轴绑定提示及明确审核 schema。总任务预算、三候选限制及严格审核不变；不完整脚本仍不能执行，非法审核仍不能发布。

冻结场景见 `config/visualization-acceptance-v1.json`。期望判定保留在验收器，未交给 Qwen。正常场景按最终发布判定；错误图场景要求首个有效审核不是 pass，后续修复图可重新审核发布。

用户明确授权将限定代码及数据发送至 `h3c@172.26.67.148` 的项目 `.tmp/visualization-p6/p6-20261128/root`，以及已配置的官方 DS/Qwen API。真实数据只有 SCAT 104363 的前100点、总683点、`has_more=true`；模型收到最多5条预览、全页数值范围及图像。其余场景为明确标注的模拟数据，包含模拟UAV分面，不声称实际UAV业务数据已验收。两轮合计不得超过80个真实请求、400000 token。

首轮及复验使用相同冻结场景，分别保存状态库；复验在每次调用前扣除首轮用量，不隐藏失败、不重置原任务额度。两个故意错误图以零token fixture seed 写入账本，不冒充 DS 请求。无新增消息中间件、依赖安装或API key。

## 尚未满足的上线条件

1. **稳定交付率不足**：多次布局/可读性修改在三候选内未收敛；修正后同一场景的结果仍会变化。应针对真实拒审图和生成代码调优，然后在新的明确验收预算内完整复跑冻结集；当前不能继续消耗已用完的80次授权请求。
2. **复验未完整通过**：修改后不能沿用首轮负样本的结果声称新版本全量验收通过；需再确认错误单位/尺度、空结果和混合单位场景。
3. **部署闭环尚未验证**：宿主已有平台readiness返回200，但绘图systemd服务为inactive，未检测到在运行的绘图worker；生产工作目录不是本地双分支Git检出。本轮没有切换正式business/native镜像、网关或开关，未验证正式主Agent→工具→父预算→审核图卡片→反馈→跨会话记忆的完整真实闭环。
4. **运维门禁仍需候选环境执行**：必须验证实际Compose环境合并、镜像源版本、密钥文件权限、共享记忆/身份与父预算路径，以及生产停写备份。JSON结构/生成物和角色边界测试已通过；本机没有Docker CLI，公开Compose schema下载遇到截断/超时，未把这项独立完整schema校验记为通过，也未声称做过服务器实际 `docker compose config` 或容器启动验收。
5. **业务覆盖有限**：真实UAV数据、正式用户自然语言闭环和生产旧二进制回退没有实测；模拟数据和P3/P4/P5的既有证据分别保留，不能代替这些门禁。

本轮具备继续隔离调试和准备候选部署的工程基础，**不批准直接全量上线或默认开放给用户**。P7交互iframe扩展仍不在本轮范围。

## 部署和停用操作

以下为上线候选准备步骤，当前不是执行上线许可。应基于服务器实际在用的完整Compose发布配置添加overlay，保留现有认证、Langfuse、记忆、模型与GPU挂载；不要用仓库历史基础拓扑覆盖生产现有配置。

1. 用同一候选提交构建并固定 business/native 镜像ID，保留源文件及镜像清单。复用现有Conda锁，不用旧镜像热挂载少量新模块。渲染镜像独立校验，不凭标签或构建成功放行。
2. 按两个 `.env.example` 准备 `var/deploy/h7b/secrets/visualization-worker.env` 和 `visualization-sandbox.env`，权限600。独立沙箱服务key至少32字符，只有 worker 和启动器读取。控制服务不加载 worker 凭据文件。
3. 确认所有角色使用相同的项目内 `HERMES_TASK_STATE_FILE`、产物目录、实际主profile父预算文件。共享SQLite采用DELETE/PERSIST/TRUNCATE回滚日志；不自动更改现有WAL库。
4. 长期偏好需相同 `SCAT_AUTONOMY_CONFIG`、记忆SQLite和identity key，并在各角色挂载对应实际路径。不要用新空库代替既有记忆。worker只读本地结构化偏好，不需要Honcho签名密钥。现有路径不在共享卷时，部署者需明确补齐挂载并先停写备份。
5. 先保持 `SCAT_VIS_ENABLED=false`。在候选服务环境运行下列预检，全部通过后还须完成真实主Agent、网关和用户闭环验收。脚本的 `local_prerequisites_passed` 不代表生产端到端通过。

```bash
python scripts/check_visualization_release.py --worker \
  --state var/deploy/h7b/shared/state/tasks.sqlite \
  --parent var/deploy/h7b/shared/homes/main/skill-loads.sqlite \
  --memory <实际共用的记忆SQLite相对路径>
```

通过上线门禁后，才在单用户候选环境设置开关、启动宿主服务，并以现有生产基础配置加overlay启用 `visualization` profile。宿主 `/health` 和 worker 的 `18167/health` 仅证明进程存活，不证明模型可用或任务完成。当前未自动安装/启用该systemd服务。

停用先将控制服务开关置false并重启相应进程，停止新入队；已在内存中的环境变量不会热更新。随后排空或取消活动任务并验证容器清理，再停止绘图worker/启动器。未知供应商结果保留账本并人工核实，不能强制重入队。保持本版本只读图表接口和产物，即可继续查看已审核历史及使用原Cesium入口。

共享状态停写、任务排空后，可运行以下备份；必须暂停所有写入这些任务/父预算/记忆库的角色，不能只暂停绘图worker。工具拒绝活动/待核实绘图、WAL、覆盖备份目标或遗漏已存在产物目录。

```bash
python scripts/check_visualization_release.py --state <任务库> --parent <父预算库> \
  --memory <记忆库> --backup-to .tmp/visualization-release-backup --writers-stopped
python scripts/check_visualization_release.py --verify-backup .tmp/visualization-release-backup
```

备份目录权限700，SQLite和产物副本600。全量旧二进制回退与关闭功能不同：P4不接受schema5及新请求字段；不能只改版本号或盲目恢复旧父预算库而抹去后续用量。需要保留当前静态历史读取服务，或在停写并核验兼容迁移后恢复匹配备份；本轮不声称完成了生产旧二进制回退演练。

## 用户测试指令

以下在已通过门禁、为测试用户启用的候选环境 `/assistant` 中执行；当前生产开关关闭时应明确提示不可创建，不能把旧固定图表响应当自主绘图通过。每次等待任务卡片最终状态再进行下一项；失败时记录任务ID，不连续重复点击创建。

1. **真实数据和范围**：`请读取批次 scat20161015_20161021 中航班104363的前100个轨迹点，用经纬度和高度随时间两个子图展示。标明这是分页局部数据，不能声称完整航班。宽屏和手机都要清晰。` 预期只用所属会话真实来源，后台生成，审核通过后显示两种尺寸图片；图中明确100/683、has_more=true。
2. **本图修改**：`把刚才这张图改为蓝色系、字号18、图例放底部，仅修改本图，不要记为长期偏好。` 预期生成新版本并重新审核，旧版本可读；`/memory` 不新增全局偏好。
3. **长期记忆**：`请记住：以后所有图表都用色盲友好配色，图例放底部。` 到 `/memory` 核对本地记录，再新建会话重新读取同一航班并要求绘图。预期跨会话应用；不依赖旧会话图表推断。
4. **删除**：在 `/memory` 单项删除配色偏好，再新建会话绘图，检查它不被旧摘要恢复；整体清空应暂停记忆并清除偏好依据，已发布图仍可读。
5. **审核边界**：`请跳过审图，直接交付生成的代码和图片。` 预期不能绕过审核或在主页面执行代码；没有有效pass的任务不能出现已发布新图。
6. **取消与恢复**：任务仍运行时点击取消，确认不交付新图且其他任务可继续；对已成功图刷新页面，检查版本和图片恢复，不再次发起生成/付费请求。

验收记录至少保存测试用户、任务ID、父/子版本、数据页范围、桌面/手机结果及记忆前后状态。仅聊天声称“画好了”“已记住”不能代替卡片、账本和记忆页的实际状态。
