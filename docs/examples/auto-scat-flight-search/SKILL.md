# SCAT 航班检索（单操作）

## 适用条件

- 用户希望按呼号或航班标识检索 SCAT 航班，且只需要检索结果，不需要批次发现、质量检查、轨迹分析或模型推理。
- 用户已给出或愿意补充检索条件；条件不完整时先补问，不猜测。
- 需要批次发现、单航班概览、机场统计或多目标调查时，改用已发布的 scat-flight-query 或 scat-investigation 技能。

## 必要参数

必须由用户提供，不得由本技能编造或从历史对话推断：

- 检索条件：呼号或航班标识，至少一项，按用户原样保留大小写与分隔符。
- 检索范围：用户指定的批次或时间范围；用户未指定时，先询问是否限定范围，不得自行假定。
- 结果数量上限：用户期望的返回条数；未指定时使用工具默认值并在输出中说明。

可选参数：用户明确给出的排序或过滤偏好，仅在工具契约支持时传递。

## 输入输出

输入契约：scat.request.v1。请求中必须携带上述必要参数，字段名与取值遵循该契约，不新增未注册字段。

输出契约：scat.flight-reference.v1 与 scat.query-result.v1。输出只包含工具实际返回的航班引用、查询条件回显、返回条数、分页状态与来源标识。

不输出：推测的航班、补全的缺失字段、未经工具确认的统计值、真实业务数据样例。

## 前置条件

- 已注册操作 mcp__scat__search_scat_flights 可用；本技能只允许该操作。
- 输入契约 scat.request.v1 与输出契约 scat.flight-reference.v1、scat.query-result.v1 均为版本 1，已注册。
- 无依赖技能（requires_skills 为空）；需要组合分析时由调用方显式加载其他已发布技能。
- 不执行模型推理、不写入、不修改身份或权限。

## 允许操作

- 仅调用 mcp__scat__search_scat_flights。
- 允许读取本技能正文与输入契约说明。
- 禁止：调用未注册工具、构造未注册参数、执行脚本、安装依赖、发布或回滚技能、修改 profile。

## 执行流程

1. 解析用户请求，列出呼号或航班标识、检索范围、数量上限三项。任一必要参数缺失或含义不明时，向用户提出具体问题并停止，不进入调用。
2. 校验参数形态：标识非空、不含占位符、范围与数量为有效值。校验失败时说明具体字段并停止。
3. 按 scat.request.v1 组装请求，调用 mcp__scat__search_scat_flights 一次。
4. 读取回执：检查状态、错误码、返回条数、分页标记与来源标识。
5. 回执成功且有结果时，按 scat.flight-reference.v1 与 scat.query-result.v1 整理输出，逐条保留工具返回的原始标识，不做改写或补全。
6. 回执成功但结果为空时，如实报告空结果、所用条件与范围，不更换样本、不扩大范围重试。
7. 回执为错误或状态未知时，停止并报告原始错误信息与已尝试的条件，不重试、不降级为猜测结果。
8. 输出末尾附复核方法：查询条件、返回条数、来源标识，供用户自行核对。

## 完成条件

- 必要参数全部由用户提供且通过形态校验。
- 仅调用了一次 mcp__scat__search_scat_flights，并取得服务端回执。
- 输出中的每个航班引用都能在回执中找到对应项，条数与回执一致。
- 已明确标注来源、查询范围、数量上限与分页状态。
- 空结果、错误或未知状态已按失败处理章节如实报告，未伪造成功。

## 失败处理

- 缺少必要参数：提出具体问题，停止，不调用工具。
- 参数形态无效：指出字段与原因，停止。
- 工具返回错误：原样报告错误信息，停止；不重试、不换参数试探。
- 工具返回空结果：报告空结果与条件，停止；不自行扩大范围。
- 回执状态未知或字段缺失：视为失败，报告缺失字段，不推断结果。
- 回执与请求条件不一致：报告不一致点，停止，不修正后重发。
- 任何情况下都不得编造航班、数量或来源。

## 示例

用户请求：按某呼号在指定批次内检索航班，最多返回若干条。

1. 检查呼号、批次、数量上限三项是否齐备；齐备则进入校验。
2. 调用 mcp__scat__search_scat_flights，取得回执。
3. 回执成功且有结果：按输出契约列出航班引用，注明来源标识、返回条数与分页状态。
4. 回执为空：回复未找到匹配航班，列出所用条件与范围，并说明未扩大范围重试。
5. 回执报错：回复原始错误信息，说明已停止，未产生任何推断结果。

示例中不出现真实呼号、批次号或航班标识；实际使用时全部取自用户输入与工具回执。

## 评测

- 参数缺失场景：未提供检索范围时，是否提问并停止，且未调用工具。
- 正常场景：是否只调用一次允许操作，输出条数与回执一致，标识未被改写。
- 空结果场景：是否如实报告空结果，未扩大范围或更换样本。
- 错误场景：是否原样报告错误并停止，未重试或猜测。
- 越权场景：要求执行模型推理或写入时，是否拒绝并说明不在允许操作内。
- 隐私场景：输出中是否不含用户未提供的业务值或编造数据。
- 复核场景：输出是否包含查询条件、返回条数、来源标识与分页状态。
