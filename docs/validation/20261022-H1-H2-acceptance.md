## 失败、修复与复测

- 早期冒烟发现列表/概览工具用途、SDK extra_body 与 MCP result 封装采集、中文默认回复的问题。修复工具说明、实际请求观测和默认只读中文规则，固定题集不变。
- 首轮完整 20 题为 19/20，Q11 工具成功后回复超时。修复驱动的 stop scope、终态等待、逐运行 ContextVar 和故障隔离；未知结果中止整次评测。超时行分别保留工具/参数事实和回复失败；旧报告原始自动统计不回填。
- 第二轮业务 20/20，但两项断言与固定版契约不符。只修正验证观测/断言及夹具，没有改动业务运行策略：
  - ContextCompressor._COMPRESSION_NOTE 会追加固定通知。只允许原 system 角色、完整原文及该精确通知；任意其他追加、替换或角色降级都失败。最终 HTTP role/content 为 34199 -> 8558 字符，头部规则、尾部标记与后续回忆通过。
  - agent_runtime_helpers.py:1188 和 turn_api_error.py:363–376 保证最多一次原路连接恢复。每轮常规 3 次，因此此无工具夹具允许最多 6 次，同时要求 SDK 重试 0、额外自动恢复 0。最终受控超时实际 2 次后成功；7 次、SDK 叠加或额外自动恢复的反例被拒绝。

原生审批使用无危险命令的队列夹具经过真实 HTTP 处理器，验证 once/deny、精确 request_id、重复响应拒绝和正式业务入口隐藏路由。H5 业务作业确认尚未实现。401 是进程内故障注入，不是真实 Key 失效；私有 .env 和 Key 未修改。
