已找到固定GBAR配置引用的 `train.pt` 与 `valid.pt`，以及对应现存CSV分区。训练CSV 31,012份、验证CSV 3,446份，文件名交集0。本轮功能验收航班100002在训练CSV分区中，且与原批次同名CSV字节一致，不在现有验证CSV分区中。

目前缺少“固定权重 → 当时训练张量 → 原始航班划分”的生成清单与摘要，因此不能仅凭当前目录证明该权重完整训练成员，也不能证明独立留出。未加载53GB训练张量、未改数据、未重新训练。详见 `training-partition-audit.json`。现有100002结果仅作功能、契约及迁移证据。

科学准入需要模型负责人提供上述可追溯清单，冻结按航班隔离的独立测试集，再按同观测窗口、同起点、同真值比较GBAR与CPU基线，报告各时域误差、覆盖/排除、失败以及置信区间。分类头目前只展示类别索引和概率；没有经过核验的类别字典，不能解释成飞行阶段或正常/异常。
