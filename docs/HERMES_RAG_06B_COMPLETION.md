## 受控知识操作与使用方式

`--rag-config services/rag/real-agent-06b-service.json`为显式启用入口。复用既有`mcp__scat__search_scat_knowledge`，参数`mode=deep`使用0.6B检索与四个真实Hermes会话；`auto`按配置长度/关键词路由；默认`fast`保留原知识检索handler。对照表中的fast指同0.6B下的单Agent问答，不能与该原始handler的耗时混为一谈。

实际调用仍须本run加载已发布aviation-knowledge正文。scope、run、预算数据库路径只从可信主运行派生，模型不能覆盖。所有子Agent请求和工具消耗同时记本次子运行与主运行额度；默认不启用，不改正式技能包。可选API的运行所有权及幂等命名空间额外绑定平台会话，不能只依赖共享服务密钥。

API v2使用真实语料和模型；无关MCP业务操作采用隔离合成后端，不查询或执行真实业务任务。实际技能加载、一次deep操作、真实四会话、父子预算共享、POST幂等、跨会话拒绝均通过，15次请求均计主预算。原API v1的跨会话检查失败保留；其幂等检查误以为返回200，固定原生协议实际返回202，修正测试后验证同run且replayed=true。详见[接入验收](validation/20261026-rag-06b-api.json)。
