# Honcho记忆与Agent设置界面

## 功能与生效范围

新增/memory与/settings，复用Vue/TypeScript，不新增依赖。记忆页面连接现有平台Honcho控制层，Hermes原生文件记忆仍保持关闭。当前用户来自平台鉴权；浏览器不能提交owner/workspace/session等身份信息。页面仅在主动查看时取记忆摘要，不持续轮询召回，更正正文与摘要不进入localStorage/sessionStorage。离开页面清空页面内存。

我的记忆：状态/队列、主动查看摘要、更正、处理记录及整体清空。更正使用稳定UUID；网络结果不明保留原UUID/原内容，只允许人工核对后重试原请求，无自动POST重放。sent只显示“已提交记忆服务”，不能解释为已形成摘要、已正确召回。Honcho空representation/peer_card不伪装成已记住。当前更正记录最多100条，仅当前用户/当前代次，清空后旧正文和当前界面不可见。

清空操作须显式确认，返回202仅说明接受；等待后台删除并精确确认workspace缺失后显示完成，不自动重新启用。删除仅针对长期记忆，不删除聊天历史、技能草稿、数据库备份/WAL，也不宣称物理介质擦除。第一版无逐条删除接口，不把聚合摘要伪装成可独立删除的事实列表。

自动学习：显示配置开关、auto_trials、可信来源总数、按pattern统计的成功数与不同input_sha数、阈值、任务/草稿/试跑及失败状态。源统计是截至查询时的已验证来源累计，不等于尚可分配来源，也不代表冷却期、每日名额或预算已通过。scheduler_observed=false时明确显示进程未核实，不用配置enabled冒充进程健康。unknown不提供自动重跑；草稿与试跑链接复用技能管理，连接作者服务后按query中的已校验ID读取。

Agent设置使用独立作者/维护入口，业务Agent及作者模型没有新增管理工具。操作者凭据只在页面内存，保存待应用提案另需独立确认凭据，操作后清空；不把供应商Key发到浏览器。

设置界面显示已注册三角色Profile的配置、凭据是否配置/目录与state.db存在状态、各层模型额度。所有磁盘读取明确runtime_observed=false；未从运行服务取得证据前不显示“已生效”。配置范围包括模型/温度/轮次、记忆字符/队列/保留参数、自动学习参数、每日及累计代理预算、只读与后台运行预算、工具组限制。模型仅限部署当前模型及已登记deepseek-flash；不开放任意URL/供应商。预算入口只允许收紧，既有累计封顶不清零、不取消。保守预留单位不是供应商token或费用；失败和unknown仍占用预留，供应商token另列。

工具组策略config/agent-tools.json为各角色“额外禁用的可选组”；空数组表示不额外禁用。主角色允许禁用scat_tasks/scat_workflows/scat_skill_scripts，后台与作者必需组锁定。脚本在配置写入前从原角色工具组里减去禁用组，只能减少能力；现有工具批准、业务权限、技能依赖及预算校验继续保留。关闭可选组可能使依赖该组的技能不可用，不能借配置给作者业务工具或给后台任意终端。

## 管理接口

机器可读定义：[OpenAPI](api/hermes-memory-settings.openapi.json)，离线导出不读取真实记忆或Key。

| 接口 | 契约 |
| --- | --- |
| GET /api/v1/hermes/memory | 原状态字段加deletion=none/pending/completed，完成必须所有旧代次删除请求确认sent |
| GET /api/v1/hermes/memory/corrections | items最多100，request_id/content/state/created；当前用户当前代次，排除cancelled |
| GET /api/v1/hermes/memory/learning | 保留原状态，增加auto_trials、patterns成功数/不同输入数、scheduler_observed=false |
| GET /v1/settings | 独立X-SCAT-Author-Key；返回白名单磁盘配置、脱敏Profile元数据、用量、当前actor提案；不返回.env、SOUL、聊天或记忆正文 |
| POST /v1/settings/preview | section、changes、expected_sha256、request_id；校验并返回before/changes，不改配置 |
| POST /v1/settings/proposals | 上述字段加confirmed=true；额外X-SCAT-Release-Key，保存pending_maintenance提案，不写实际配置 |

前端设置路径为同源/author-api/v1/settings*，复用独立作者代理；记忆仍走业务同源/api/v1/hermes/memory*。配置503表示目标清单未注册/不可读，不回退到另一个Profile根目录。配置冲突/非法权限409、缺少作者凭据401、缺独立确认403、类型/确认错误422。无Web apply、Docker、安装依赖、任意路径或任意命令接口。

提案请求号为UUID，同一actor+同一完整内容重试幂等，换内容/用户冲突。提案绑定目标文件摘要和完整注册清单摘要；清单更改后旧提案失效，防止同内容被套用到另一个根目录。只允许项目内非链接目标；拒绝配置文件及其父目录的符号链接。私有提案库var/agent-settings/proposals.sqlite权限0600，每actor最多1000提案，列表最新100条。
