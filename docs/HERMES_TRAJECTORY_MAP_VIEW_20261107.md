# 轨迹底图、三维定位与全屏修复

日期：2026-11-07，Asia/Shanghai。用户要求二维默认街道底图，修复三维找不到轨迹及初始北美视角，并增加全屏查看。

仅改前端，复用现有Vue/Cesium/ECharts依赖；不安装依赖、不调用模型或重算预测、不重启服务器或后台容器。暂存限项目`.tmp/map-view-repair`，正式证据`var/validation/20261107-map-view-repair`。实际轨迹仅在浏览器内用于显示和断言，不保存新原始轨迹文件；截图使用合成数据。

## 原因与实现

- 只读轨迹图表在缺少可解析时间时没有time_key；旧归一化器无条件丢弃这种轨迹，导致三维收到零条轨迹、相机停留在Cesium默认区域。新增显式静态几何模式，保留原始经纬度/高度和点序；内部序号不当秒数，隐藏无依据的时间播放、曲线和姿态估计。
- 地理二维图默认使用OpenStreetMap街道底图及已有Cesium二维模式，保留米制相对坐标图和原有有时序的播放功能，不使用GCJ-02底图作为WGS84默认。
- 以真实轨迹包围球立即定位，自动按视口计算距离；增加定位轨迹按钮。二维与三维提供全屏/退出全屏，浏览器拒绝时给出明确提示。
- 使用官方OSM瓦片URL与可见版权标注，不预取/离线批量下载；底图网络失败时保留轨迹显示及错误提示。

技术依据：[Cesium Camera](https://cesium.com/learn/cesiumjs/ref-doc/Camera.html)、[Viewer](https://cesium.com/learn/cesiumjs/ref-doc/Viewer.html)、[OSM瓦片说明](https://operations.osmfoundation.org/policies/tiles/)。
