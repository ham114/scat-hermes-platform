# 前端工作台

目标：首页直接进入对话，留出清晰的输入区；不展示数据集名称、批次、规模、数据库、端口或工程阶段。导航仅保留对话、历史会话、数据浏览，数据总览/航班/预测评估在主动进入数据浏览后再选择。首页不自动请求数据目录或统计。文案限标题、操作、状态以及影响确认决定的必要信息。

复用现有真实HTTP/SSE对话、稳定请求号、停止/恢复、确认任务和七类结果展示。流程目录主动展开，任务只在有实际任务或用户展开时展示；保留批准参数和unknown禁止重跑。执行过程及结果来源可按需展开。读取历史、查看结果或改变布局不提交计算。

历史只读取现有归属约束的threads/runs/结果API。接口尚未返回原始用户提问和自定义会话标题时，显示时间与实际历史回复，不虚构完整聊天记录或生成假标题。继续对话使用所选thread，未确认请求保留原UUID，不自动重发。切换时拒绝旧请求结果覆盖新上下文。

设计采用中性浅色默认、单一青绿色强调、细边框和适度留白；保留深色切换。无装饰性数据卡、假在线状态、未接通的功能按钮或首页数据集大图。原二维/三维结果页面与图表继续复用，重型业务页面按路由延迟加载。

## 已实现

- `/` 与 `/assistant` 共用新对话工作台；浅色默认、绿色强调、深色切换及移动导航。首页初始只有问题输入与三个通用建议，不展示SCAT/UAV、批次、规模或数据库；浏览器验证初始API请求为0。

- `/data` 提供按需航班总览、检索、评估及结果编号恢复，保留原二维/三维展示。业务路由延迟加载，依赖不变。
