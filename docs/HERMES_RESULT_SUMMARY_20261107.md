# 一轮绘图分析的主结果与数据来源汇总

日期：2026-11-07，Asia/Shanghai。用户要求修复一次绘图分析出现多份“结果”的展示错误。

## 实现

- “查看来源→查看数据”只提供一个本轮主展示区；原来逐条工具回执平铺图表的方式改为“主图/分析 + 默认折叠的数据来源明细”。回复中的文字分析保持一份。飞行阶段、飞行计划、概况等原始数据仍可展开核对。
- 相同航班、过滤范围、坐标布局及时间原点的轨迹按源分页起点与抽样步长恢复原序号，合并排序，重复点去重。查询额外motion字段不同但实际图层字段一致时可合并几何；额外字段保留在各自原始来源中。冲突点、不同航班/范围/单位/时间原点不强行合并，使用同一个主展示区切换查看。
- 展示已加载去重点数、源总点数、取数次数与去重点数；只有序号0至total-1连续完整覆盖才说明完整源序列。抽样、缺页时明确并非完整逐点航迹；不插值补点、不伪造时间或姿态。失败、停止、中断的运行明确提示“已取得部分数据，不代表分析已完成”。
- 每份回执仍经过现有归属、ID、摘要与图表来源绑定校验后才参与展示；合并图不冒用某一单份回执的内容摘要。多来源的浏览器布局保存按全部来源ID与摘要绑定；单份结果沿用原保存键。切换会话丢弃在途旧数据。
- 仅用户点击后执行现有结果GET读取，并发最多4、每次最多64份，读取失败时保留成功部分并提示。不会为了展示重新执行取数、模型或预测，不改原始回执、运行状态或后台配置。
